# Глобальные предпочтения

## Язык и общение
- Отвечай по-русски. Код, имена переменных и коммиты — на английском.
- Пиши коротко и по делу: результат, затем 1–3 строки пояснения. Без вступлений и пересказа задачи.
- Объясняй простыми словами, без жаргона; команды давай готовыми к копированию.

## Экономия токенов
- Простые задачи (поиск, переименование, тексты, опечатки, форматирование, мелкие правки стилей, однотипные замены) передавай субагенту `quick` — он работает на дешёвой модели.
- Сильную модель используй для планирования, архитектуры и сложной отладки; само выполнение плана — на основной модели.
- Читай файлы частями и только нужные; не перечитывай то, что уже прочитано.
- Не выводи файлы целиком в ответ — показывай только изменённые места.
- Не запускай долгие команды и полные сборки без необходимости; предпочитай точечные проверки.

## Сайт: визуальный стиль
Взято из интерфейса проекта (`src/ui/work-view/styles.css`, `docs/public/docs.json`).

**Шрифты**
- Заголовки: Space Grotesk (плотный трекинг, `letter-spacing: -.04em` для крупных).
- Текст: Hanken Grotesk, межстрочный 1.4.

**Цвета** (задавать токенами в `:root`)
- Текст `--ink: #1e2333`, приглушённый `--muted: #45516b`, метаданные `#68728a`.
- Акцент — фиолетовый: `--violet: #6043c3`, на тексте `#5432b7`, фокус `#6b4ce0`.
- Фон `--canvas: #f5f7fd`, карточки `--surface: #ffffff`, линии `--line: #dce3f7`.
- Статусы: успех `#18875d`, внимание `#cf542f`, в работе `#6841e4`, нейтральный `#737e9d`.
- Документация: синий `#3B82F6` (светлый `#EFF6FF`, тёмный `#1E40AF`).

**Стиль**
- Светлый, воздушный интерфейс, скруглённые карточки (радиус ~13px), тонкие рамки вместо теней.
- Обязательно поддерживать тёмную тему и версию для телефона.
- Сохранять существующую стилистику; новые цвета — только через токены.
