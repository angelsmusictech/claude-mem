# Claude Code + OmniRoute: глобальные настройки

Настройки действуют во всех проектах (кладутся в `%USERPROFILE%\.claude`).

## Что внутри
| Файл | Назначение |
|---|---|
| `settings.json` | Подключение к OmniRoute и распределение моделей |
| `CLAUDE.md` | Язык, стиль ответов, правила экономии, стиль сайта |
| `agents/quick.md` | Субагент на дешёвой модели для простых задач |
| `install.ps1` | Установщик для Windows |

## Как переключаются модели
- **Режим планирования** (Shift+Tab) → сильная модель.
- **Обычная работа** → основная модель (`model: opusplan`).
- **Простые задачи и все субагенты** → дешёвая модель. Claude сам передаёт их агенту `quick` по правилам из `CLAUDE.md`.
- Какие именно сторонние модели стоят за этими тремя уровнями, решаете вы в OmniRoute. Там же можно собрать комбо с запасными провайдерами, чтобы при лимите запрос уходил к следующему.

## Установка
1. В дашборде OmniRoute выберите три модели (или комбо): дешёвую, основную и сильную. Скопируйте их ID.
2. Скачайте папку `omniroute-setup`, откройте в ней PowerShell и выполните:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```
3. Ответьте на вопросы: адрес, ключ и три ID моделей.
4. Откройте новое окно PowerShell и запустите `claude`. Команда `/model` покажет текущую модель.

Существующие файлы не теряются: установщик сохраняет их копии с суффиксом `.bak-дата`.
